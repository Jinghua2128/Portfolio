Self-initiated / Full-stack Web

Multilingual Questionnaire Platform

A responsive survey application demonstrating multilingual form design, validation and database-backed response handling.

Problem

Online questionnaires need to guide people through required questions clearly while keeping submitted responses organised for review.

My Role

Independent design and full-stack development of this self-initiated application, from the survey interface to response storage and export.

Solution

An English/Chinese multi-step interface with a progress indicator, required-field validation, rating questions, an NPS-style scale and optional feedback. A Flask backend stores responses through SQLAlchemy in a MySQL-compatible database.

Response Workflow

The platform includes an admin response viewer and CSV export for reviewing collected answers. The interface is designed for desktop and mobile.

Technologies

HTML, CSS, JavaScript, Python, Flask, SQLAlchemy, MySQL-compatible database and responsive web design.

Technical Considerations

Form progress, required answers, language switching and backend storage must remain consistent through a multi-step response.

The focus: a clear path from completing a multilingual form to reviewing structured responses.

Year 3 Major Design Capstone / Team Project

EchoWorks

An interactive training experience developed with Singapore Red Cross as the industry partner.

Problem

The project explored how interactive scenarios could support workplace communication training and feedback.

My Role

Web development and full-site revamp, Firebase integration, AR quick-reference and interface improvements within a multidisciplinary team.

Technical Architecture

The browser-based experience uses Firebase Authentication and Firestore for account-backed progress, with scenario progression/gating and an admin dashboard.

Key Features

Responsive training UI, user progress tracking, scenario flow, backend integration and an AR quick-reference experience.

Collaboration

UI work was contributed by Gracie, and the first scenario scene by KaiMing. My work focused on the web, Firebase and AR portions described here.

Technical Considerations

Connecting account state, training progress and scenario access required a consistent flow across the interface and backend.

Personal Project / Python

PoliteLoad

A Python utility for archiving personal submissions and authorised course materials from POLITEMall/Brightspace.

Problem

Collecting personal submissions and course files one at a time can make it difficult to keep a local archive organised.

My Role

I developed this as a personal automation tool focused on materials accessible through the user's own account.

Solution

The Python workflow focuses on browser automation, login/session handling, course and material discovery, file downloads and large-file handling.

Scope

It is intended for the user's own authorised educational files. It does not bypass access controls or grant access to someone else's materials.

Technologies

Python, browser automation and file handling.

Technical Considerations

Reliable downloads depend on maintaining an authorised session and handling file sizes without losing the user's place in the course workflow.

Next iteration: refine the interface and packaging to make the workflow easier to use.
